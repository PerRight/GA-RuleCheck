# AutoCAD 2027 플러그인 (GaRuleCheck.dll)

엔진(Python)이 판정하고, 이 플러그인은 **도면 스냅샷 추출 → 엔진 호출 → 결과 표시**만 하는 어댑터다.

> **v0.5.0(10-18) 실도면 연결** — GA_ 레이어가 없는 실제 GA(1/1000 시트, 원점≠AP/기선, 한 시트에 여러 뷰)를 레이어를 바꾸지 않고 검사: `GARCLINK` 마법사(치수표·축척 → 측면도 영역 → AP/FP/기선 → 역할 지정 → 조종위치), `GARCROLE`, `GARCROLESHOW`, 준비 상태 카드, 블록 펼침·호/원/곡선 지원. **컴파일 확인만(오류·경고 0)** → 아래 확인표 **26~33**.
> **v0.4.0(10-18) 기능 3종** — ① 버전 기록·비교 창·생산팀 전달(PDF/PNG) ② 떠 있는 로고 패널(Ctrl+.) ③ 마우스 오버 하이라이트·충족/미충족 툴팁·체크리스트 연동. **AutoCAD 2027 DLL·.NET 10 참조로 컴파일 확인(오류·경고 0, Claude 작업 환경)** — AutoCAD 안 실행은 미확인 → 아래 확인표 **15~25**. 판정 색이 바뀜: **충족 = 파랑**(전에는 초록), 미충족 = 빨강, 확인 필요 = 주황.
> v0.1(2026-10-12) AutoCAD 2027에서 빌드·실행 확인. v0.3 소스는 10-12 16:04 빌드됨(리포트 생성 확인).
> **v0.3.2(10-12 3·4차 수정: layer_counts 전송, 'GA' 접두 레이어 감시 신호, 엔진 주소 허용 목록·리다이렉트 금지 / 10-13 '발표 모드' → '라벨 확대'·명령 `GARCLARGE`)는 빌드 미확인** — `install.ps1`로 다시 빌드할 것.
> v0.3.1(10-12 오류 수정: Extractor·EngineClient·ShipInfoView·DocWatcher·Dto)은 10-12 18:34 사용자 PC에서 빌드 성공(`Polyline2d.VertexPosition`, `Vertex2dType.SplineControlVertex`, `Vertex3dType.ControlVertex`, `HttpClientHandler.UseProxy` 모두 컴파일됨). **실기 동작은 아래 확인표 1~14로 확인할 것** — 오류가 나면 메시지·스크린샷 그대로 Claude에게.

## 준비물
- AutoCAD 2027 (.NET 10) — LT 버전은 .NET 플러그인 불가
- .NET 10 SDK (`dotnet --list-sdks` → 10.x). 설치: `winget install Microsoft.DotNet.SDK.10`
- (Visual Studio를 쓸 경우 2026 이상 — VS 2022는 .NET 10 대상 빌드 불가)
- AutoCAD 2025/2026(.NET 8)에서 쓰려면 `-p:TargetFramework=net8.0-windows -p:AcadDir=...`로 따로 빌드 (버전 간 바이너리 호환 없음)
- Python 3.10+ (엔진 서버)

## 빌드
```powershell
cd autocad\GaRuleCheck
dotnet build -c Release
# AutoCAD 경로가 기본값이 아니면:
dotnet build -c Release -p:AcadDir="D:\Program Files\Autodesk\AutoCAD 2027"
```
결과: `bin\Release\net10.0-windows\GaRuleCheck.dll`

## 자동 로드 설치 (권장 — NETLOAD·서버 실행 생략)
AutoCAD를 **모두 닫고** PowerShell에서:
```powershell
cd autocad
powershell -ExecutionPolicy Bypass -File .\install.ps1
```
1. 빌드 → 2. `%APPDATA%\Autodesk\ApplicationPlugins\GaRuleCheck.bundle`에 설치(AutoCAD 2027 시작 시 자동 로드) → 3. `GARC_ENGINE_DIR`·`GARC_PYTHON` 사용자 환경변수 설정(`GARC` 입력 시 엔진이 꺼져 있으면 최소화 창으로 자동 실행).
- 코드를 고친 뒤에도 같은 명령으로 다시 설치한다(AutoCAD는 번들 복사본을 쓰므로 `bin` DLL이 잠기지 않는다).
- 처음 한 번 보안 경고가 뜨면 "항상 로드". 매번 뜨면 옵션 → 파일 → 신뢰할 수 있는 위치에 번들 폴더를 추가.
- 제거: `.\uninstall.ps1`

## 수동 실행
1. 엔진 서버 켜기 (별도 터미널):
   ```powershell
   cd engine
   python -m garc serve        # http://127.0.0.1:8765
   ```
   환경변수 `GARC_ENGINE_DIR`에 engine 폴더 경로를 넣어 두면, 연결 실패 시 플러그인이 한 번 자동 실행을 시도한다.
2. AutoCAD에서 `NETLOAD` → `GaRuleCheck.dll`
3. 샘플 도면 열기: `samples\S140_rev0_base.dxf` (DXF를 열고 DWG로 저장해도 된다)
4. `GARC` → 오른쪽 팔레트에 결과가 뜬다.

## 화면 (v0.2)
- **리본 'GA RuleCheck' 탭** — 검토(검사 시작·지금 검사·감시 중지) / 입력(선박 정보·조종위치·초기 설정) / 표시·기록(표시 켜기/끄기·리포트)
- **팔레트** (AutoCAD 다크 테마)
  - 상단: 전체 판정 점·문구, `rev · 도면 · 시각`, 엔진 연결 상태, [다시 검사] [도면 표시] [리포트]
  - **검토 탭**: 규칙 카드 — 상태 띠·배지, 메시지, 현재값/허용값 게이지, 최악 조건, 제안, [대상 보기], [근거 ▾](미검토 범위). 상태가 바뀌면 맨 위에 "새 위반 / 해결" 배너
  - **선박 정보 탭**: LOA·L·AP·FP·기선·눈높이·용골 거치일·단위, 흘수 조건 표 편집 → [저장 후 검사]. AP·FP·기선은 [도면에서]로 점 지정, [조종위치 지정]으로 GA_EYE 점 생성/이동
  - **이력 탭**: revision 타임라인(추가/삭제/수정, Undo 표시, 판정 변화)
  - 하단: 면책 문구 고정
- **도면 위 표시** (Transient): 위반 객체 빨강/검토 불가 주황, 시선(파랑/빨강), 최악 조건 수선(하늘), 허용 한계선·충돌격벽 허용 구간(노랑), 기준점, 라벨("사각 433.8 m", "허용 상단 z ≤ 22.45 m", "d=11.00 m" …). 라벨은 맑은 고딕 TrueType 스타일 `GARC_LABEL` 사용
- **리포트**: DWG 옆에 `<도면>_GA검토_<시각>.html` 저장 후 브라우저로 열림 — 요약, 측면도 SVG, 규칙별 판정식·중간값·미검토 범위, 입력 요약, 변경 이력. 인쇄(PDF 저장) 가능
- 다른 도면 탭으로 바꾸면 팔레트가 그 도면 결과로 바뀌고, 선박 정보가 입력된 도면은 자동 감시

### v0.3 추가

- **카드 호버 강조**: 팔레트 카드에 마우스를 올리면 해당 객체가 도면에서 자홍색으로 강조

- 카드 배경이 검게 칠해질 수 있던 문제 수정(투명 부모 위 Clear)

### v0.4 추가 (10-18)
- **버전 기록**: 도면을 저장하면(또는 `GARCVERSION`) 작성자·수정 사유(규정 위반 / 피드백 / 기타)·관련 규정 조항 또는 피드백 내용·메모를 받아 버전을 남긴다. 저장 위치: 도면 옆 `<도면이름>.garc\`(versions.json + v{n}.raw.json — GA_ 레이어 스냅샷, 도면 내용이므로 PC 밖으로 보내지 않음). GA_ 레이어·선박 정보가 그대로면 묻지 않는다. 저장할 때 자동으로 묻는 것은 그 도면을 **GARC로 감시 중일 때만**이다(감시 전이면 `GARCVERSION`으로 직접 기록). 감시 중이고 마지막 검사 뒤에 바뀐 것이 있으면 기록 직전에 한 번 더 검사해 그 결과를 함께 남긴다(감시 전이면 검사 결과 없이 형상만 기록).
- **버전 비교 창**(`GARCCOMPARE`, 리본 '버전'): 아무 두 버전(기본 직전 → 현재). **나란히 보기**(두 칸이 같이 확대·이동) / **겹쳐 보기**(이후 투명도 슬라이더) / **차이만 강조**(추가 초록 빗금, 삭제 빨강 파선, 변경 노랑 — 이전 점선·이후 실선). 변경마다 번호 표식(추가 ○ · 삭제 □ · 변경 ◇), 표식·목록을 누르면 그 위치로 확대. 오른쪽 **변경 내역**: 변경 전·후 값, 수정 사유, 이번 수정으로 해결된 위반. '해결'은 이후가 충족이거나 객체가 삭제(그리고 규칙을 판정할 수 있을 때)된 경우만이고, 판정 못 함·입력 누락·적용 제외로 바뀐 것은 **⚠ 확인 필요**로 따로(주황) 적는다. 요약 줄에 두 버전의 전체 판정과 확인 필요 개수. [도면에 표시]로 AutoCAD 도면 위에도 임시 표시(그 도면 탭이 활성일 때만). 변경 내용·해결 판단은 엔진(`/v1/compare`) 계산.
- **생산팀 전달**: 비교 창 버튼 → PDF 또는 PNG 한 장(A4 가로) — 도면 번호(`GARC_DWG_NO`, 없으면 파일 이름), vX → vY, 날짜, 작성자, 수정 사유, 차이 강조 그림, 번호 매긴 변경 목록, 범례. 흑백 인쇄에서도 색 + 선 모양 + 표식 모양 + 기호(+ − ~)로 구분.
- **떠 있는 로고**(오른쪽 아래): 클릭 또는 `Ctrl+.` → 검토 패널이 로고 쪽에서 0.25초에 펼쳐짐, 다시 누르면 접히고 로고만 남음(도킹 팔레트도 숨김). 미충족 개수 빨간 배지(미충족이 없고 확인 필요만 있으면 주황 숫자, 엔진 응답 없음·판정 불가면 주황 '!'). 도면 탭을 바꾸면 그 도면 상태로 바뀜. 드래그로 이동, 위치·열림 상태는 `%APPDATA%\GaRuleCheck\ui.json`. 스크린리더에 '펼쳐짐/접힘' 상태 제공. 로고 그림은 DLL 옆 `garc_logo.png`(없으면 기본 표식). `GARCLOGO`로 숨기기.
- **마우스 오버**: 판정 대상 객체에 커서를 올리면 상태 색 굵은 외곽선(닫힌 도형은 반투명 채우기) + 툴팁 "✔ 충족 / ✖ 미충족 / ⚠ 확인 필요 — 규칙, 기준, 실제, 차이, 가이드". 닫힌 도형 안쪽에 올려도 잡힌다(공간 인덱스). 계산은 40 ms에 한 번.
- **점검 항목**: 규칙 카드 안에 객체별 줄(미충족 → 확인 필요 → 충족). 줄에 마우스 → 도면 강조, 클릭 → 그 객체로 확대. 탭 줄 오른쪽 **[미충족만 보기]**(숨긴 확인 필요 개수는 주황으로 남김).
- 전체 판정 문구가 길면 두 줄로 보여 잘리지 않음.

## 명령
| 명령 | 동작 |
|---|---|
| `GARC` | 팔레트 열기 + 현재 도면 감시 시작 (레이어·라벨 스타일 없으면 생성) |
| `GARCCHECK` | 즉시 다시 검사 |
| `GARCOFF` | 감시 중지, 표시 지우기 |
| `GARCSETUP` | GA_ 레이어 5개 + 라벨 스타일 + `GARC_*` 특성 틀 생성 |
| `GARCSHIP` | 선박 정보 탭 열기 |
| `GARCEYE` | 조종위치(GA_EYE 점) 지정 — 1개면 이동, 없으면 생성 |
| `GARCPICK` | `AP`/`FP`/`BASE` 위치를 도면에서 클릭해 특성에 저장 (한 번 검사해 단위를 안 뒤에 가능) |
| `GARCTOGGLE` | 도면 위 표시 켜기/끄기 |
| `GARCREPORT` | HTML 검토 리포트 저장·열기 |
| `GARCLARGE` | 라벨 확대 켜기/끄기 (라벨 글자·선 두께·표식 크기 2.5배, 판정은 그대로). 옛 `GARCPRESENT`는 v0.3.2부터 없음 |
| `GARCHEALTH` | 엔진 연결 확인 |
| `GARCVERSION` | 지금 상태를 버전으로 기록 (저장할 때도 자동으로 묻는다) |
| `GARCCOMPARE` | 버전 비교 창 (나란히·겹쳐·차이만, 변경 목록, 생산팀 전달) |
| `GARCPANEL` | 떠 있는 로고의 검토 패널 열기/닫기 (`Ctrl+.`) |
| `GARCLOGO` | 떠 있는 로고 보이기/숨기기 |
| `GARCLINK` | **실도면 연결 마법사** — ① 도면 문자에서 치수·축척 후보 읽기 → 확인 창 ② 측면도 영역 ③ AP·FP(AP+LBP 가능)·기선 클릭 ④ 선체·충돌격벽·장애물(객체/레이어)·구상선수 역할 ⑤ 조종위치 → 검사 + 준비 상태. 레이어·객체는 바꾸지 않음 |
| `GARCROLE` | 고른 객체에 역할 붙이기/해제 (Hull/Obst/Bhd/Bulb/Eye/Clear) |
| `GARCROLESHOW` | 엔진이 판정에 쓴 객체를 역할별 색으로 임시 표시(다시 실행하면 끔) |

## 설계 메모
- **표시는 Transient(임시 그래픽)만** 쓴다. 도면 DB를 수정하지 않으니 Undo 기록이 오염되지 않고 저장 파일에도 남지 않는다.
- **이벤트는 "다시 검사" 신호로만** 쓴다. 매번 GA_ 레이어 전체를 스냅샷으로 보내고, 무엇이 바뀌었는지는 엔진이 계산한다(→ Undo/Redo/복사/레이어 변경 어느 경로든 동기화가 맞음).
- 엔진 연결 실패·플러그인 예외 → 항상 "검토 불가"로 표시. 충족(파랑)으로 남지 않는다.
- **판정 색**: 충족 파랑 · 미충족 빨강 · 확인 필요 주황. 버전 비교의 추가 초록 · 삭제 빨강(파선) · 변경 노랑과 섞이지 않게 충족에 초록을 쓰지 않는다.
- **버전 비교도 판단은 엔진**: 무엇이 바뀌었고(handle 기준) 어떤 위반이 해결·발생했는지는 `/v1/compare`가 계산하고, 비교 창은 그리기·고르기·내보내기만 한다.
- **판단 없는 추출**: 폴리선 호는 bulge 값만 보내고 분할은 엔진이 한다. 블록은 삽입점만 보내며, 엔진이 GA_EYE 외 레이어 블록을 멈춘다.
- **엔진 주소는 루프백만**: `GARC_ENGINE_URL`이 127.0.0.1·localhost·::1의 http 주소가 아니면 무시하고 기본값을 쓴다. HttpClient는 시스템 프록시를 쓰지 않는다(`UseProxy = false`).
- **문서 ID**: FingerprintGuid + 열린 문서마다 새 GUID. 같은 원본에서 복사한 도면을 동시에 열어도 엔진 세션이 섞이지 않는다(문서를 다시 열면 이력은 새로 시작).
